# 🔐 Random Password Generator

A Python command-line application that generates random passwords based on user-selected character types. Developed as part of the **OASIS Infobyte Python Programming Internship – Task 3**.

## ✨ Features

- Generates passwords with a user-defined length
- Minimum password length of 8 characters
- Supports:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Requires at least 2 character types
- Guarantees at least one character from every selected type
- Validates invalid password lengths
- Validates invalid character-type selections
- Allows users to generate multiple passwords without restarting

## 🛠️ Technologies Used

- Python 3
- `random`
- `string`
- Command-line interface

## ▶️ How to Run

Open the terminal in the project folder and run:

```bash
python password_generator.py
