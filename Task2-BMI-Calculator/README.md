# 🧮 BMI Calculator

A simple Python command-line BMI Calculator developed as part of the **OASIS Infobyte Python Programming Internship – Task 2**.

## ✨ Features

- Accepts weight in kilograms (kg)
- Accepts height in meters (m)
- Calculates BMI using the formula:
  
  `BMI = weight / (height²)`

- Displays BMI rounded to 2 decimal places
- Classifies BMI into:
  - Underweight: BMI < 18.5
  - Normal: BMI 18.5–24.9
  - Overweight: BMI 25–29.9
  - Obese: BMI ≥ 30
- Handles non-numeric input
- Rejects zero and negative values

## 🛠️ Technologies Used

- Python 3
- `input()`
- Basic arithmetic
- Conditional statements
- Exception handling

## ▶️ How to Run
